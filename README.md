# 📊 Retail Sales Intelligence Dashboard

An interactive retail sales analytics dashboard built using Python, Pandas, Streamlit and Plotly. This project transforms retail sales data into meaningful business insights through interactive visualizations and KPI metrics.

## 🎯 Project Objective

The objective is to analyse retail sales data, understand business performance, identify profitable products and customers, and support data-driven business decisions.

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit
- Plotly
- CSV Dataset

## 📌 Dashboard Features

### 1. Executive Overview
- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Units Sold
- Monthly sales and profit trends
- Category sales distribution
- Regional sales performance

### 2. Sales Analytics
- Sales by customer segment
- Profit by region
- Yearly sales comparison

### 3. Product Analytics
- Profit by product subcategory
- Top 10 subcategories by sales
- Product profitability analysis

### 4. Customer Analytics
- Customer sales versus profit analysis
- Top 10 customers by sales
- Customer order analysis

### 5. Data Quality
- Missing value analysis
- Dataset row counts
- Filtered data preview

## 🎛️ Interactive Features

- Filter by order year
- Filter by product category
- Filter by region
- Switch between INR and USD display
- Editable USD-to-INR reference conversion rate

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/srisanth-k/Retail-Sales-Intelligence.git
```

2. Navigate into the project:

```bash
cd Retail-Sales-Intelligence
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the dashboard:

```bash
streamlit run streamlit_app_professional.py
```

5. Upload your Superstore CSV dataset through the dashboard if it is not available in the default data folder.
